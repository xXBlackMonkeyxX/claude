# Repository Documentation

This directory contains repository-wide documentation for the Claude Code Plugin Collection.

## Documentation layout

```text
 docs/
 ├── README.md
 ├── architecture/
 │   └── README.md
 └── guides/
```

### `architecture/`

Contains structural documentation and design conventions for the repository and its plugin ecosystem.

### `guides/`

Contains maintenance, validation, development, and workflow guides.

## Plugin documentation

Plugin-specific documentation remains inside each plugin package so that every plugin stays self-contained and distributable.

For the complete plugin catalogue and repository-level tooling, see the root [`README.md`](../README.md).

## Maintenance

Keep documentation aligned with the actual repository structure. When paths, plugin contracts, validation rules, or developer tooling change, update the relevant documentation in the same change.
